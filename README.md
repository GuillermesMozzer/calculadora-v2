# Calculadora V2

Precificação de talentos Taking — cockpit moderno com motor de margem completo.

## Modos

- **Precificar** — perfil individual, simuladores, breakdown de custo
- **Ratecard** — tabela de referência (~360 perfis)
- **Montar Time** — proposta comercial com alçadas
- **Saúde** — monitoramento de margem real da operação

## Stack

React 18 · TypeScript · Vite · Tailwind CSS

## Dev

```bash
npm install
npm run dev
```

Abre em http://localhost:4010

## Deploy

Configurado para Vercel (`vercel.json` com SPA rewrite).
